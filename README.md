# Steall Hub - Steal A Pet And Ride It

Script auto-farm bersih & termodifikasi khusus untuk **Delta Executor** (Mobile & PC).

## 🚀 Fitur yang Dimodifikasi
- **100% Bebas Telemetri / Tracker:** Skrip tracker ScriptBlox & RScripts serta webhook pihak ketiga telah dihapus.
- **Instant Teleport:** Auto-steal dan kembali ke plot secara instan tanpa perlu berjalan manual.
- **Auto Farm Lengkap:**
  - Auto Steal Cage
  - Auto Place Cage ke plot
  - Auto Open Cage saat timer selesai
  - Auto Train & Upgrade Treadmill
  - Auto Equip Best Pets & Auto Rebirth
- **Player Mods:** WalkSpeed slider dan Noclip.

## 📥 Cara Menjalankan di Delta Executor

Gunakan `loadstring` berikut di tab Delta Executor Anda:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/MyusiZ3/Steall/main/Steal-A-Pet-And-Ride-It_with_ui.lua"))()
```

*(Catatan: Karena repositori bersifat private, untuk loadstring langsung di Roblox lewat link raw GitHub Anda memerlukan Personal Access Token atau mengubah repositori menjadi publik jika ingin bisa diakses siapa saja).*
